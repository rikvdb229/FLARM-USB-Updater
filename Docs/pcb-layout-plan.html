Step 2: Board Size

Target: 55mm × 28mm (2165 × 1102 mil)

USB-C is ~9mm wide, RJ45 is ~16mm wide × ~13mm deep, FT232RL SSOP-28 is ~10mm body. With boost converter zone on top, 28mm height accommodates all zones. Width of 55mm gives room for the signal chain.

If components don't fit at 28mm height, increase to 30mm. Board can be wider (up to 60mm) if needed — prefer clean routing over smaller board.

Step 4: Copper Pour Setup

Bottom Layer GND Pour (primary ground return)

  1. Place → Copper Pour on Bottom layer
  2. Net: GND
  3. Clearance: 8 mil
  4. Fill: Solid
  5. Cover entire board outline

Top Layer GND Pour (fills empty space)

  1. Place → Copper Pour on Top layer
  2. Net: GND
  3. Clearance: 10 mil (slightly larger to avoid solder bridging on 0402 pads)
  4. Fill: Solid
  5. Cover entire board outline
  6. Priority: lower than bottom pour
Top layer GND pour fills empty space around signal traces, improving EMI shielding and thermal dissipation. The 10mil clearance prevents solder bridging risk on 0402 passives.

Via Stitching

  • Place GND vias every 6-8mm across the board
  • Critical locations: around boost zone perimeter, near USB connector, along board edges
  • Extra vias near U3 GND pin and FT232RL GND pins
  • Via size: 0.3mm drill / 0.6mm pad

Step 5: Routing Order — All Nets

Step 6: Verification Checklist

  • DRC passes with zero violations
  • D+/D- length mismatch < 20 mil
  • VUSB, VBOOST, SW traces all ≥ 20 mil
  • V12_OUT traces ≥ 15 mil
  • Boost switching loop (U3→L1→D1→C3) total path ≤ 15mm
  • No signal traces through boost zone
  • Bottom GND pour covers full board, 8 mil clearance
  • Top GND pour fills remaining space, 10 mil clearance
  • GND vias stitched every 6-8mm
  • All GND pads connect via short stub → via → bottom pour (no long GND traces)
  • USB D+/D- on same layer, no vias, ≥3mm from SW node
  • All component courtyards ≥ 0.5mm from board edge
  • Mounting holes at opposite corners (M2.5, GND net)
  • Test points TP1-5 placed and labeled
  • Silkscreen: board name, connector labels, LED labels, voltage warnings

Key Design Principles

1. GND via strategy GND pads → short stub → via → bottom pour. Never route long GND traces on top.
2. Boost zone isolation No signal traces pass through U3/L1/D1 area. Keep USB and RS232 on opposite side.
3. USB D+/D- integrity Stay on TOP only. No vias, no layer changes. Match lengths within 20 mil.
4. Decoupling placement Caps touch their IC pins. ≤2mm trace from cap to IC power pin.
5. Left-to-right signal flow USB-C → FT232RL → MAX3232 → RJ45. Clean, logical layout.
6. Prefer routing clarity Board can be wider if needed. Clean routing beats smaller board.
