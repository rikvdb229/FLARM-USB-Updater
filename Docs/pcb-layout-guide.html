0. Schematic Verification (Before PCB)

⚠️ Do this in EasyEDA schematic before touching the PCB layout. Open schematic → click U1 (FT232RL) → check these pins.
  • U1 TEST pin → GND CRITICAL — physical pin 26, SSOP-28. TEST=1 = chip in factory test mode, USB won't work.
  • U1 CTS# → GND CRITICAL — prevents Windows COM port hang
  • U1 DSR# → GND IMPORTANT
  • U1 DCD# → GND IMPORTANT
  • U1 RESET# → NC OK — has internal pull-up, internal POR sufficient
  • U2 T2IN (pin 10) → GND — confirmed in netlist
  • All charge pump caps C6–C9 connected correctly
  • CC1 (R4 5.1kΩ) and CC2 (R5 5.1kΩ) → GND on USB-C
  • RJ45 pinout matches FLARM IGC spec (pins 1/2 = 12V, 5/6 = RS232)

How to set net widths in EasyEDA Pro

  1. In PCB editor: Design → Design Rule → Net Class
  2. Create class POWER → assign nets: VUSB, VBOOST, $1N2860 → Width: 20mil
  3. Create class POWER_12V → assign net: V12_OUT → Width: 15mil
  4. Or manually: route trace → right-click → Select Connected Copper → Properties → change width
  5. Re-run DRC to confirm no violations

3. D+/D− Equal-Length Differential Pair

⚠️ Most important signal-integrity task on this board. D+ and D− must be equal length and routed as a tightly coupled pair. A mismatch causes USB bit errors.

Routing path

J1 (USBC1)  ──→  D2 (USBLC6-2SC6)  ──→  U1 (FT232RL)
 A6/B6 (UD+)     pin 1/6 (I/O1)          USBDP
 A7/B7 (UD−)     pin 3/4 (I/O2)          USBDM

Option A — Differential Pair Router (preferred)

  1. Delete any existing D+ and D− traces
  2. Route → Interactive Router → enable Differential Pair in the toolbar
  3. Click on UD+ net at J1 — EasyEDA automatically routes both D+ and D− together
  4. Route from J1 → D2 → U1 in one continuous move
  5. Keep pair spacing ≤ 6mil (traces may touch — fine for USB 2.0)
  6. Both traces on same layer, no vias

Option B — Manual with length check

  1. Route D+ (UD+) from J1 → D2 → U1 normally at 10mil
  2. Route D− (UD−) the same path, keeping it alongside D+
  3. Select D+ trace → Properties → note Length
  4. Select D− trace → Properties → note Length
  5. If mismatch > 20mil: add serpentine meander on the shorter trace (Insert → Trace)
Clearance rules for D+/D−: Keep ≥ 3mm from the MT3608 SW node ($1N2860) · Keep ≥ 2mm from RS232 traces · Route on top layer only

4. Boost Converter Switching Loop

MT3608 switches at 1.2MHz. A large switching loop radiates EMI that can corrupt USB data on the same board.

Placement rules

  • U3 SW pin → L1: trace ≤ 5mm, width 20mil HIGHEST PRIORITY TRACE
  • L1 output → D1 anode: ≤ 5mm, width 20mil
  • D1 cathode → C3: ≤ 5mm, width 20mil
  • R1 + R2 (FB divider) within 5mm of U3 FB pin (pin 3)
  • C1 + C2 (Vin caps) within 3mm of U3 VIN pin (pin 5)
  • GND via directly adjacent to U3 GND pin (pin 2)
  • No USB or RS232 signal traces routed through boost zone EMI

5. GND Copper Pour — Bottom Layer Only

Bottom layer only. Do NOT add top layer copper pour — risk of tombstoning on 0402 passives during reflow due to thermal mass imbalance.

How to add in EasyEDA Pro

  1. Make sure all traces are routed first
  2. Place → Copper Pour (or shortcut: Shift+P in PCB editor)
  3. Set Layer: Bottom (B.Cu)
  4. Set Net: GND
  5. Set Clearance: 8mil
  6. Set Fill: Solid
  7. Click to trace around the full board outline → double-click to close
  8. EasyEDA fills the pour automatically — click Rebuild All Copper Pour if needed

Via stitching

  1. Place → Via → set Net to GND, drill 0.8mm, pad 1.2mm
  2. Place vias every 6–8mm across the board, especially around boost converter and USB connector
  3. Place at least 2 vias near U3 GND pin and 2 vias near J1 GND pins
  4. Rebuild copper pour after placing vias

6. Recommended Routing Order

  1. VUSB (20mil) — J1 VBUS → C1 → C14 → U1 VCC (pins 4+20) → U2 VCC (pin 16) → U3 VIN (pin 5)
  2. GND star — short GND connections from each IC GND pin to nearest via (bottom pour handles the rest)
  3. Boost switching loop (20mil) — U3 SW → L1 → D1 → VBOOST (keep tight and compact)
  4. V12_OUT (15mil) — D1 cathode → C3/C4 → R1 top → RJ1 pins 1+2
  5. D+/D− differential pair (10mil matched) — J1 → D2 → U1 USBDP/USBDM
  6. UART_TX / UART_RX (10mil) — U1 pin 1 → U2 pin 11 (TX) · U2 pin 12 → U1 pin 5 (RX)
  7. RS232_TX / RS232_RX (10mil) — U2 T1OUT → RJ1 pin 6 · RJ1 pin 5 → U2 R1IN
  8. V3V3 / R7 (10mil) — U4 Vout → V3V3 → R7 → RJ1 pin 3
  9. LED nets (10mil) — U1 CBUS0 → LED2 cathode · U1 CBUS1 → LED3 cathode · VUSB → R6/R8/R9 → LED anodes
  10. Feedback + EN (10mil) — VBOOST → R1 → $1N2875 ← R2 ← GND · $1N2875 → U3 FB · $1N2847 → U3 EN ← R3 ← VUSB
  11. CC pull-downs (10mil) — J1 CC1/CC2 → R4/R5 → GND
  12. Add GND copper pour — bottom layer, full board, clearance 8mil
  13. Add via stitching — GND net, 0.8mm drill, every 6–8mm
  14. Run DRC — fix all violations before Gerber export

8. Pre-Order Checklist

  • DRC passes with zero violations
  • D+ and D− trace lengths within 20mil of each other
  • VUSB, VBOOST, SW traces all ≥ 20mil wide
  • V12_OUT traces ≥ 15mil wide
  • Boost switching loop (U3→L1→D1→C3) is compact — SW trace ≤ 5mm
  • No signal traces routed through the boost converter zone
  • Bottom layer GND copper pour covers full board, clearance 8mil
  • GND vias stitched every 6–8mm
  • All component courtyards ≥ 0.5mm from board edge
  • Board outline: 2000 × 950 mils (or confirmed size based on RJ45 courtyard)
  • Schematic: FT232RL TEST pin → GND CRITICAL
  • Schematic: CTS#, DSR#, DCD# → GND CRITICAL
  • Gerbers exported: all layers + drill file
  • JLCPCB Gerber viewer shows no missing copper or shorts
  • CPL file (component placement) verified for all 32 components
  • BOM matches all 32 components with correct C-numbers
