Block Layout on the Sheet

Follow left-to-right signal flow and top-to-bottom power flow.

┌─────────────────────────────────────────────────────────────────────┐ │ [MT3608 + L1 + D1 + C1-C4 + R1-R3] │ │ BOOST CONVERTER (top centre) │ │ │ │ [J1 USB-C] [FT232RL U1] [MAX3232 U2] [J2 RJ45] │ │ [D2 USBLC6] [C10-C13] [C5-C9] [R7] │ │ [R4, R5] │ │ [C14] │ │ USB-C USB-UART RS232 CONNECTOR │ │ (left) (centre-L) (centre-R) (right) │ │ │ │ [LED1 LED2 LED3 + R6 R8 R9] │ │ INDICATORS (bottom centre) │ └─────────────────────────────────────────────────────────────────────┘

Spacing Tips

  • Leave ~3–4 grid squares between blocks — room for bypass caps and labels
  • Place decoupling caps directly beside their IC's power pins
  • Cluster charge pump caps C6–C9 around U2 (only connected to U2)
  • Stack boost feedback divider R1, R2 vertically below U3's FB pin
  • Group LEDs in a horizontal row (mirrors PCB edge placement)

Project Setup

  1. Open EasyEDA Pro desktop app
  2. File → New Project → name it FLARM-USB-Updater
  3. A blank schematic sheet opens — this is your only sheet
  4. File → Save to Computer → save to d:\CodeProjects\FLARM-USB-Updater\EasyEDA\
    Filename: FLARM-USB-Updater.epro
  5. Right-click the title block → Edit → set Title: FLARM USB Updater · Rev: 1.0

How to Place Any Component

  1. Open Parts panel (left sidebar)
  2. Click the JLCPCB tab
  3. Type the C-number in the search box (e.g. C8690)
  4. Click the result → symbol loads
  5. Click on schematic to place · press R to rotate first if needed
  6. Press Esc when done
For resistors and caps: search by C-number exactly the same way. EasyEDA will auto-fill JLCPCB part number and footprint.
4

How to Connect Components

Wires

Press W → click start pin → click end pin → press Esc

Net Labels (for distant signals)

Press N → type the net name → click a pin to attach.
Any two pins sharing the same net name are connected, even without a physical wire.

Power Ports (GND, VUSB, etc.)

Press P → search GND → place on every GND pin.
For custom nets (VUSB, VBOOST, V12_OUT): use Net Label N.

No-Connect

Press X → click any unused pin that is intentionally unconnected.

Block 1 — MT3608 Boost Converter

Place: U3 C84817, L1 C135264, D1 C8598, R1 C25741, R2 C25905, R3 C25744, C1 C45783, C2 C307331, C3 C45783, C4 C1779

-- Main circuit --
U3 Vin  ── net label VUSB
U3 GND  ── GND power port
U3 EN   ── R3 one side
R3 other side ── net label VUSB        (10kΩ pull-up, always enabled)
U3 SW   ── L1 one side
L1 other side ── net label VBOOST
U3 FB   ── junction of R1 and R2
R1 other side ── net label VBOOST    (100kΩ, top of divider)
R2 other side ── GND                  (5.1kΩ, bottom of divider)

-- Input decoupling (VUSB rail) --
C1 + side ── VUSB,  C1 − ── GND     (22µF/25V 0805)
C2 one side ── VUSB, C2 other ── GND (100nF 0402)

-- Output caps (VBOOST net) --
C3 + side ── VBOOST, C3 − ── GND   (22µF/25V 0805)
C4 + side ── VBOOST, C4 − ── GND   (4.7µF/25V 0805)

-- Backfeed diode D1 (B5819W) --
D1 anode   ── net label VBOOST
D1 cathode ── net label V12_OUT
Verify: VBOOST → L1, R1, C3, C4, D1 anode only.
Verify: V12_OUT → D1 cathode and RJ45 section only.

Block 2 — MAX3232 RS232 Transceiver

Place: U2 C7258, C5–C9 all C307331

-- Power --
U2 VCC ── VUSB
U2 GND ── GND
C5 + ── VUSB, C5 − ── GND          (100nF VCC bypass)

-- Charge pump caps --
C6: C1+ pin ↔ C1− pin             (100nF)
C7: C2+ pin ↔ C2− pin             (100nF)
C8: V+  pin ── GND                (100nF)
C9: V−  pin ── GND                (100nF)

-- Signal pins --
U2 T1IN  ── net label UART_TX
U2 T1OUT ── net label RS232_TX
U2 R1IN  ── net label RS232_RX
U2 R1OUT ── net label UART_RX
U2 T2IN  ── GND                      (unused channel — tie low)
U2 R2IN  ── X (no-connect)
U2 R2OUT ── X
U2 T2OUT ── X

Block 3 — FT232RL USB-UART

Place: U1 C8690, C10 C1779, C11–C13 C307331

-- Power --
U1 VCC   ── VUSB
U1 VCCIO ── VUSB                    (IO voltage = 5V)
U1 AGND  ── GND
U1 GND   ── GND
C10 + ── VUSB, C10 − ── GND        (4.7µF bulk)
C11 ── VUSB ↔ GND                  (100nF VCC bypass)
C13 ── VUSB ↔ GND                  (100nF VCCIO bypass)

-- 3V3OUT (internal LDO) --
U1 3V3OUT ── C12 ── GND             (100nF — do not load heavily)
U1 3V3OUT ── also to R7             (section 10)

-- USB data pins (CRITICAL — connects to D2 in Block 4) --
U1 USBDP ── net label UD+             (→ D2 I/O1 → J1 D+)
U1 USBDM ── net label UD−             (→ D2 I/O2 → J1 D−)

-- UART signals --
U1 TXD ── net label UART_TX
U1 RXD ── net label UART_RX

-- LED signals --
U1 CBUS0 (TXLED#) ── net label TXLED
U1 CBUS1 (RXLED#) ── net label RXLED

-- Tie to GND (NOT no-connect!) --
U1 TEST ── GND
U1 CTS# ── GND
U1 DSR# ── GND
U1 DCD# ── GND
U1 RI#   ── GND    ← ring indicator input, tie low when unused

-- No-connect (X) --
U1 RTS#   ── X
U1 DTR#   ── X
U1 RESET  ── X    ← internal pull-up, leave as NC
U1 OSCI   ── X    ← internal oscillator, no crystal needed
U1 OSCO   ── X
U1 CBUS2  ── X
U1 CBUS3  ── X
U1 CBUS4  ── X
PWREN# does not appear in the EasyEDA C8690 symbol — this is normal, ignore it.

Block 4 — USB-C Input

Place: J1 C165948, D2 C7519, R4 C25905, R5 C25905, C14 C307331

-- Power --
J1 VBUS ── net label VUSB
J1 GND  ── GND  (all GND pins)

-- CC pull-downs (identifies as power sink) --
J1 CC1 ── R4 ── GND               (5.1kΩ)
J1 CC2 ── R5 ── GND               (5.1kΩ)

-- USB data through ESD clamp D2 (USBLC6-2SC6) --
J1 D+  ── D2 I/O1 ── U1 UD+
J1 D−  ── D2 I/O2 ── U1 UD−
D2 VCC ── VUSB
D2 GND ── GND
C14 ── VUSB ↔ GND                 (100nF bypass on D2 VCC)

-- Unused J1 pins --
J1 SBU1, SBU2        ── X
J1 D+/D− secondary  ── X  (USB-C has 2 pairs; only route one)
USBLC6-2SC6 has a specific SOT-23-6 pin layout — verify I/O1/I/O2/VCC/GND labels match the datasheet before wiring.

Block 6 — LED Indicators

Place: LED1 C2297, LED2 C2297, LED3 C2296, R6 C11702, R8 C11702, R9 C11702

-- Power LED (always on) --
VUSB ── R6 ── LED1 anode
LED1 cathode ── GND

-- TX LED (active-low, sinks when FT232RL transmits) --
VUSB ── R8 ── LED2 anode
LED2 cathode ── net label TXLED     (→ U1 CBUS0)

-- RX LED (active-low, sinks when FT232RL receives) --
VUSB ── R9 ── LED3 anode
LED3 cathode ── net label RXLED     (→ U1 CBUS1)
Anode = positive side (triangle base) · Cathode = negative side (bar)
All resistors 1kΩ → 3 mA at 5V — well within FT232RL 6 mA sink limit.

Clean Up Schematic

  1. Add component values to all passives (double-click → edit Value field):
    R1–R9: 100k, 5.1k, 10k, 5.1k, 5.1k, 1k, 10R, 1k, 1k
    C1–C14: 22µF/25V, 100n, 22µF/25V, 4.7µF, 100n, 100n, 100n, 100n, 100n, 4.7µF, 100n, 100n, 100n, 100n
  2. Verify all designators match R1–R9, C1–C14, LED1–3, U1–U3, L1, D1–D2, J1–J2
  3. Add a design note text box: 
    FLARM USB Updater v1.0
USB → 12V boost → FLARM RJ45
FT232RL uses usbser.sys (no driver install)
13

ERC — Electrical Rules Check

  1. Design → Electrical Rules Check
  2. Resolve all errors:
    "Pin unconnected" → check FT232RL unused pins have X flags
    "Power pin not driven" → verify VUSB net has a source (J1 VBUS)
  3. Warnings for intentional no-connects are OK if X flags are placed
Target: 0 errors, 0 warnings
14

Verification Checklist (before export)

  • VBOOST connects only to: MT3608 output + C3 + C4 + D1 anode
  • V12_OUT connects only to: D1 cathode + J2 pin 1 + J2 pin 2
  • U1 TEST → GND (not NC!)
  • U1 CTS#, DSR#, DCD# → GND
  • U1 CBUS0 → TXLED net → LED2 cathode
  • U1 CBUS1 → RXLED net → LED3 cathode
  • J2 pin 3 → R7 → U1 3V3OUT
  • J2 pins 9, 10 (shield) → GND
  • D2 placed in D+/D− path between J1 and U1
  • R4, R5 (5.1kΩ) on CC1 and CC2 → GND
