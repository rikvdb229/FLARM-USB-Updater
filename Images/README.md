# Images

Photos and screenshots used in the main README and for sharing the project.

Suggested files (drop them here with these names so README links stay stable):

| File | What | Use |
|---|---|---|
| `board-top.jpg` | assembled board, top-down, clean background | README hero shot + GitHub social preview |
| `board-in-use.jpg` | plugged into a laptop USB-C with RJ45 to a FLARM | shows the value prop ("no bench supply") |
| `board-back.jpg` | back silkscreen artwork (logo / licence / trademark) | shows the custom branding |
| `terminal-update.png` | serial terminal / FLARM update succeeding | proof of function (optional) |
| `enclosure.jpg` | the 3D-printed case (with board inside) | add after the print is done |

**Formats:** JPG for photos (smaller), PNG for screenshots. Keep each under
~1–2 MB so the repo stays lightweight.
